# D-003: Licences

- Date: 2026-10-04
- Status: Proposed

## Decision

- Software: Apache-2.0. **Accepted.**
- Hardware: CERN-OHL-P-2.0. **Proposed, pending written agreement of the
  co-designer** (permissive, so kit makers can build on it).
- Data: CC-BY-4.0. **Proposed.**

## Alternatives

- Permissive vs copyleft for hardware (CERN-OHL-P vs CERN-OHL-S).
- No explicit hardware licence.

## Rationale

A permissive licence maximises adoption by kit makers while keeping attribution.

## Accepted cost

Others may commercialise derivatives without contributing back.

## Revisit if

The co-designer does not agree, or a partner requires a different licence.
